Политика конфиденциальности

Дата последнего обновления: 10 сентября 2026 г.

1. Общие положения

Настоящая Политика конфиденциальности персональных данных действует в отношении всей информации, которую приложение «ДЕЛО.РУ» может получить о Пользователе во время использования приложения.

Использование Приложения означает безоговорочное согласие Пользователя с настоящей Политикой и указанными в ней условиями обработки его персональной информации.

2. Персональные данные

Какие данные мы собираем:

  • ФИО: для идентификации пользователя и персонализации сервиса
  • Email: для связи, восстановления пароля и отправки уведомлений
  • Номер телефона: для верификации аккаунта и экстренной связи
  • СНИЛС: для идентификации в государственных системах (при необходимости)
  • Пароль: хранится в зашифрованном виде
  • Фотография профиля: для визуальной идентификации

3. Цели сбора информации

  1. Идентификация Пользователя в Приложении
  2. Предоставление доступа к персонализированным ресурсам
  3. Установление обратной связи с Пользователем
  4. Обеспечение безопасности и предотвращение мошенничества
  5. Подтверждение достоверности персональных данных
  6. Предоставление клиентской поддержки

4. Защита данных

Приложение принимает необходимые меры для защиты персональной информации от неправомерного доступа, уничтожения, изменения или распространения.

Меры защиты включают:

  • Шифрование паролей современными алгоритмами
  • Использование протокола HTTPS
  • Регулярное резервное копирование
  • Ограничение доступа сотрудников к данным
  • Регулярный аудит безопасности

5. Передача данных третьим лицам

Персональные данные не передаются третьим лицам, за исключением:

  • Для исполнения обязательств перед Пользователем
  • По запросу судов и правоохранительных органов
  • Для защиты прав Приложения при нарушении условий использования
  • С согласия субъекта персональных данных

6. Права Пользователя

Пользователь имеет право:

  1. Получать информацию об обработке своих данных
  2. Требовать уточнения, блокирования или уничтожения данных
  3. Отозвать согласие на обработку данных
  4. Обжаловать действия оператора
  5. Удалить аккаунт и все связанные данные
